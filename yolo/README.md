# 엘리베이터 객체인식(YOLO) 클래스 — 1차 확정본 (2026-10-19, 추가 2026-10-20)

검사기준 통합검색 데이터(연혁집 현행 조문, 표준화 협의, 판정 지침 별표2 불합격 내용, 현장용어 사전)로 뽑은 엘리베이터 탐지 클래스.

- `data.yaml` — YOLO 클래스 75개(0~74, 1순위 43 + 2순위 32). 0~73 = 1차 확정, 74 = `tactile_block`(점형블록, 17.1.5.5, 사용자 지정 2순위). **번호를 바꾸지 말 것.**
- `엘리베이터_객체인식_클래스_1차.xlsx` — 클래스별 한글 이름·위치·별칭·근거 조항·관련 불합격 항목, 3순위 10개(나중), 불합격 79행 → 클래스 배정표.
- `classes.py` — 클래스 목록(키, 한글 이름, 위치, 별칭, 근거 조항).
- `check.py` — 근거 조항 원문에 별칭이 실제로 있는지 확인(출력 없으면 통과).
- `build_xlsx.py` — 엑셀·data.yaml 생성(불합격 행 배정 `FM`, 번호 고정 `FIXED`, 우선순위 직접 지정 `PR` 포함).

다시 만들기: `build/` 에서 `python build.py` 를 먼저 돌린 뒤(`base_el.json`·`fail.json`·`data.json` 필요) `python yolo/check.py && python yolo/build_xlsx.py`.

바꿀 때 규칙
- 번호 = `build_xlsx.py` 의 `FIXED` 순서(우선순위로 다시 매기지 않음).
- 추가: `classes.py` 에 넣고 `FIXED` **맨 뒤**에 키를 적는다. 1·2순위만 data.yaml 에 들어가므로 계산상 3순위인데 넣을 거면 `PR` 에 직접 지정. `FIXED` 에 안 적은 새 1·2순위는 맨 뒤에 붙고 경고가 나온다.
- 빼기: `classes.py` 에서 지워도 `FIXED` 에서는 지우지 말 것 — 그 번호는 '(삭제 …)' 자리로 남고(경고 출력) 뒤 번호는 그대로.
