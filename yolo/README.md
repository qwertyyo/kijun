# 엘리베이터 객체인식(YOLO) 클래스 — 1차 확정본 (2026-10-19)

검사기준 통합검색 데이터(연혁집 현행 조문, 표준화 협의, 판정 지침 별표2 불합격 내용, 현장용어 사전)로 뽑은 엘리베이터 탐지 클래스.

- `data.yaml` — YOLO 클래스 74개(0~73, 1순위 43 + 2순위 31). **확정본: 번호를 바꾸지 말 것.**
- `엘리베이터_객체인식_클래스_1차.xlsx` — 클래스별 한글 이름·위치·별칭·근거 조항·관련 불합격 항목, 3순위 10개(나중), 불합격 79행 → 클래스 배정표.
- `classes.py` — 클래스 목록(키, 한글 이름, 위치, 별칭, 근거 조항).
- `check.py` — 근거 조항 원문에 별칭이 실제로 있는지 확인(출력 없으면 통과).
- `build_xlsx.py` — 엑셀·data.yaml 생성(불합격 행 배정 `FM` 포함).

다시 만들기: `build/` 에서 `python build.py` 를 먼저 돌린 뒤(`base_el.json`·`fail.json`·`data.json` 필요) `python yolo/check.py && python yolo/build_xlsx.py`.
